1. Python：把程序分成能理解的小部分
目录定位：BV1qW4y1a7fU，P51–61 函数，P85–90 文件，P91–98 异常/模块/包，P111 以后进入面向对象部分。
入口：https://www.bilibili.com/video/BV1qW4y1a7fU/?p=51
项目用法：用函数分别完成读表、预处理和预测；用类表示数据集和网络；把模型、训练、预测分成几个文件；用 CSV/JSON 保存样本清单和实验记录。图片路径不存在或文件打不开时，给出可理解的提示。

2. 环境与包管理：给项目单独准备一套依赖
目录定位：BV1bqKE6pEmD，P1 使用 Conda 的原因，P2 Anaconda/Miniconda，P3 环境管理，P4 包管理，P5 源管理。
入口：https://www.bilibili.com/video/BV1bqKE6pEmD/?p=3
项目用法：选一种隔离方式即可。PDF 允许 Conda、uv、venv；可用 venv 创建项目环境，记录 Python 和各依赖版本，提供安装命令。显卡较新时，按实际硬件选择兼容的 PyTorch 构建，不照搬旧教程版本。

3. Git：保留一步步做出来的过程
目录定位：BV1HM411377j，P4 工作区与文件状态，P5 添加和提交，P7 diff，P9 gitignore，P12 本地与远程关联，P13 明确讲 Gitee，P16–19 分支与工作流。
入口：https://www.bilibili.com/video/BV1HM411377j/?p=13
项目用法：按真实完成的阶段提交，例如数据整理、残差块、训练脚本、结果分析、文档。gitignore 排除虚拟环境、缓存和不宜入库的大文件；记录依赖和运行说明。当前先保留本地 Git 历史，之后由用户推送到 Gitee。

4. NumPy：把图片当作数组处理
目录定位：BV1ReshzoEgG，P73 属性、P74 创建 ndarray、P75 类型转换、P76 数列、P77 基本函数、P78 统计、P79 去重排序、P80 矩阵运算。
入口：https://www.bilibili.com/video/BV1ReshzoEgG/?p=73
项目用法：处理像素数组、计算均值和标准差、统计图片尺寸或前景比例、累计混淆矩阵。混淆矩阵就是把“真实是什么、被认成什么”记成一张计数表，便于查看常见错误。

5. Pandas：把样本与训练记录整理成表
目录定位：同一课程 P83–94 数据结构、索引、排序和运算；P98 CSV/TSV 读写；P103 去重；P107–108 缺失值；P109–110 合并；P111 分组聚合；P113 交叉表。
入口：https://www.bilibili.com/video/BV1ReshzoEgG/?p=98
项目用法：每张图片占一行，列出路径、类别和所属数据划分；处理缺失/重复记录；按类别统计数量；保存每轮训练结果及逐图预测结果。训练、验证和测试的划分以同一张样本表或同一组索引为准，防止图像与标签错配。

6. Matplotlib：把过程和结果画清楚
目录定位：同一课程 P118–127，绘图步骤、图表结构、折线、刻度、标题、多图和常见图形。
入口：https://www.bilibili.com/video/BV1ReshzoEgG/?p=118
项目用法：画类别数量柱状图、样本图、训练/验证损失与准确率曲线、混淆矩阵和错分样例。图题和图例说明数据来自哪个集合，不只展示正确预测。
注意：这门课的部分分集前缀与标题内容错位。PDF 短链跳到 P59，但其具体标题仍是 SQL 窗口函数；因此按实际标题定位，不把 P59 当成 NumPy 起点。

7. PyTorch：把训练、选模型和最终评价分开
目录定位：BV1e34y1M7wR，P47 数据加载，P48 初始化，P49 反向传播，P50 验证，P51 最优模型保存，P52 曲线；P54–57 测试和推理；P93–98 自己的数据集准备、划分、加载、归一化、训练和推理。
入口：https://www.bilibili.com/video/BV1e34y1M7wR/?p=47
项目用法：Dataset/DataLoader 提供小批图片；模型输出各类别分数；交叉熵衡量预测与标签的差距；优化器根据反向传播调整参数。每批执行清零梯度、前向计算、损失、反向传播、更新参数。验证集用于选择最好的轮次，测试集用于最后报告结果。预测时切换 eval 模式、关闭梯度计算，并复用训练时的确定性预处理。

8. 手写 ResNet：理解并实现跳跃连接
目录定位：同一课程 P103–104 残差块原理，P105–107 Batch Normalization，P108–110 网络参数，P112–113 残差块代码，P114–115 ResNet18 搭建，P116 训练测试。
入口：https://www.bilibili.com/video/BV1e34y1M7wR/?p=112
项目用法：用 PyTorch 基础层自己编写残差块和各个阶段，不直接调用 torchvision.models.resnet18 充当手写实现。直观上，残差块把输入保留一路，再与卷积处理后的结果相加。两路数组形状一致才能相加；通道数或尺寸改变时，用投影分支做匹配。输入是小图片时可调整首层步幅等设置，说明调整理由。

9. 迁移学习：知道预训练模型怎样复用
目录结论：上述 PyTorch 课程的 118 个分集标题中，没有明确以“迁移学习”“预训练”或“微调”为题的章节，因此不声称该目录已证明它系统讲解了迁移学习。
通用知识补充：加载别人先训练好的参数，替换适合本任务的输出层，再冻结部分层或继续微调，这就是常见复用方式。花卉参考项目使用的正是这一思路。
考核安排：说明基本思想即可；主体仍是自己搭建的 ResNet 和实际训练，不用迁移学习替代手写网络。
官方补充：https://docs.pytorch.org/tutorials/beginner/transfer_learning_tutorial.html

完整项目的一条主线
确定分类问题 -> 整理数据表 -> 看类别数量与样本 -> 划分训练/验证/测试 -> 手写残差块和 ResNet -> 训练并保存最佳参数 -> 用独立测试集评价 -> 对新图片预测 -> 分析错分 -> 记录实际结论、依赖和运行方式。
